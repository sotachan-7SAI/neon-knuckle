03 // CONTROLS（下に続きます）

← → ↑ ↓ / WASD移動（↑↓で奥・手前）。← か → をすばやく 2 回で走る
J / Z攻撃（連打でジャブ → 裏拳 → ハイキック → とどめ）。とどめは何も押さない＝宙返り蹴り／前＝飛び回し蹴り／↑↓＝足払い
走りながら J飛び蹴り（遠くから一気に届く）
K / X / Spaceジャンプ（空中で J。前に跳ぶ＝飛び蹴り／真上＝打ち下ろし）
L / C必殺・三連回転（裏拳 → 足払い → 宙返り蹴り。体力を少し使う）。方向を入れながら＝突進二連蹴り
U / V波動（気弾）。押しっぱなしで溜まり、離すと撃つ。Lv.2 → Lv.3 → MAX と強くなり、Lv.3 からは敵をつらぬく。↑↓を入れながら＝1 段階上から始まる（体力を少し使う）
H連携技（必殺ゲージ 1 本）。近くの敵 1 体に合計 100 ダメージ。自分の技に合わせて、相手もその技を受ける動きをする
Y超必殺（ゲージ 3 本）。飛んでいってつかみ、持ち上げて叩きつける。ボスにも最大体力の 3 分の 1。まわりの敵もまとめて吹っ飛ぶ。ゲージは攻撃を当てる・食らう・ガードする、で溜まる
カプセル倒した敵がときどき落とす。拾うと約 25 秒、その敵の能力が使える（U がその技に変わる：3連射・ロケット・光の玉・念動波・ジェット突進・真空斬り。怪力・俊足・連打は体が強くなる）。魔女と超能力は ↑↓＋U で落雷
しかけ自販機は近くで殴ると飲み物が出る／マンホールに敵を落とせる（自分も落ちる）／バナナの皮・暴走トラック・プレス機・火を噴く床は敵にも効く／「押すな」ボタンは押すと何かが起きる
全5面1 商店街 → 2 ボタン工場 → 3 駅（電車から敵が降りる・自動改札・動く歩道）→ 4 遊園地（コーヒーカップ・びっくり箱）→ 5 何もない空間（ワープ床・扉）。タイトルで数字の 1〜5 を押すと、その面から始まる
コンティニュー共闘は無制限。やられても何度でも降ってくる（回数は集計に出るだけ）
落ちている武器の上で J拾う（棒・バット・鉄棒・石・ゴミ箱・メリケンサック）。持ったまま J＝殴る（3 連発）／U＝投げる。当てるたびにすり減り、使い切るとこわれる
I / Shiftよける（そのまま＝後ろへ跳ぶ／← →＝前転／↑↓＝横っ飛び）。少しの間無敵
O / F（押しっぱなし）ガード（正面の軽い攻撃を受け止める。重い技とつかみは防げない）
敵に歩いて近づくつかむ → J でひざ蹴り、方向＋J で投げ（ガードしている敵にも効く）
Esc / Mポーズ ／ 音楽のオンオフ
VR左手＝動きと大技: スティック 移動／押しこみ 走る／トリガー 波動（長押しで溜め）／グリップ 連携技／Y 必殺／X 超必殺。右手＝基本: トリガー 攻撃／A ジャンプ／B よける／グリップ ガード／スティック上下 大きさ／スティックを 0.5 秒押しこむ＝視点の切りかえ（俯瞰 ⇔ 背中から。T キーでも）。右スティックを左右に倒しても何も起きません。VR の中では、視界の左はしに操作の表が出ています

キャラ以外（敵・ステージ・音）はすべてこのゲーム用に描き起こしたオリジナルです。動きは格闘モーション（主人公＝女性格闘、敵＝空手、ボスだけカンフー）で付けています。ゲームパッドにも対応（X 攻撃／Y 気弾／A ジャンプ／B 必殺／RB よける／LB ガード／RT 走る／LT 連携技／右スティック押しこみ 超必殺）。Enter でも開始できます。
